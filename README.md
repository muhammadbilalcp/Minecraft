# Minecraft by Bilal

A full-featured 3D voxel sandbox and survival game built with Three.js, inspired by and integrated with [muhammadbilalcp/Minecraft-by-bilal](https://github.com/muhammadbilalcp/Minecraft-by-bilal).

## Features & Highlights

- **Voxel Engine & Infinite World**: Infinite procedural voxel terrain chunking, dynamic block lighting, day/night cycles, skydome with dynamic sun and moon phases.
- **Authentic Minecraft Assets**:
  - **Mojang Textures**: Authentic block textures (`stone`, `stonebrick`, `dirt`, `grass`, `sand`, `sandstone`, `bedrock`, `coal_ore`, `iron_ore`, `gold_ore`, `diamond_ore`, `lava`, `water`, `leaves`, `logs`).
  - **Sound Effects Engine**: Real sound effects for block digging, breaking, placement, walking footsteps, glass shattering, and UI clicks (`public/sounds/`).
  - **Typography & UI**: Authentic `Minecraft.woff` typography, favicon icons, and Mojang GUI toolbar textures.
  - **Steve & Dressing Room**: Classic Steve skin and interactive 3D character wardrobe.
- **Grand 3-Floor Mountain Palace & Fortress**:
  - **Floor 1**: Grand Great Hall, Golden Royal Throne, red carpet, and soaring chandeliers.
  - **Floor 2**: Imperial Art Gallery, Royal Library with enchanting tables, and high arch bridge spanning the canyon.
  - **Floor 3**: Emperor's Master Bedroom Penthouse Suite with king-size canopy bed, cozy brick fireplace & chimney, marble spa bath, and obsidian royal treasury vault.
- **Owner-Exclusive Security System**:
  - Protected access strictly for **Muhammad Bilal** (`muhammadbilalcp@gmail.com` and `mongolance080@gmail.com`).
  - Interactive gate authorization modal with guest visitor control.
- **Creative Mode in Palace**:
  - Seamless Creative Mode flight (double-tap Space) and limitless block placement inside the grand fortress.
- **Clean Crafting System**:
  - Streamlined crafting menu with instant item search, category filters, and recipe previews.
- **Multiplayer & Survival**:
  - Peer-to-peer multiplayer, mobs, Nether dimension portal, and Ender Dragon boss fight.

## Controls

- `WASD`: Move player
- `Double-tap W`: Sprint
- `Space`: Jump / Swim up (Double-tap in Creative: Toggle fly)
- `Shift`: Crouch / Fly down
- `Left Click`: Mine / Break blocks / Attack
- `Right Click`: Place blocks / Open doors, chests, furnace, crafting
- `1 - 9` or `Mouse Wheel`: Select hotbar slot
- `E`: Open Inventory & Crafting
- `F3`: Debug HUD overlay
- `Esc`: Pause menu & settings
